# ICAO Speed Trainer V2

Instalowalna aplikacja webowa do szybkiej nauki alfabetu i cyfr ICAO.

## Tryby treningu

- Znak → słowo ICAO
- Słowo ICAO → znak
- Nasłuch pojedynczego znaku
- Depesza ze słuchu: 2–6 znaków czytanych po kolei
- wybór lektora lub automatyczna rotacja dostępnych głosów i akcentów

## V2

- osobne statystyki skuteczności, liczby prób, serii i czasu dla każdego ćwiczenia
- lotniczy system progresji z XP i stopniami od Kadeta do Dowódcy eskadry
- bieżąca misja i wizualne fazy lotu
- adaptacyjne powtórki trudnych znaków
- migracja postępu z poprzedniej wersji

## Uruchomienie

```bash
mise install
npm install
npm run dev
```
